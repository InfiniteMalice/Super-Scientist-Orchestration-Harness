## Requirement disposition

- Cognitive records remain diagnostic unless an existing governed proposal
  independently authorizes a state transition. Peer agreement, diversity,
  compilation, trace, reward, and evaluation records add no claim, policy,
  progress-head, or protected-evaluator authority.
- Capability evidence remains task-scoped and explicitly
  `VERIFIED`, `SELF_REPORTED`, or `UNKNOWN`. Operational diversity remains
  separate from reviewer independence.
- Collaboration is bounded by declared peers, topology, depth, requests,
  contributions, resources, and termination conditions.
- Procedure compilation validates declared inputs and registered tools,
  retains invalid and inconclusive outcomes, and delegates valid procedures
  to the existing progress-plan types and calculations.
- Harness extensions reuse the existing campaign, evidence, trace, and reward
  primitives. Missing metadata uses the implemented availability states and
  is never fabricated.
- The additive 0007 migration retains append-only enforcement and 0001-0006
  compatibility. Complete 0.3 bundles reconstruct and replay accepted records
  through the coordinator; 0.2 bundles create no synthetic 0007 rows.
- The cognitive inspection surface is read-only and kind-discriminated. The
  offline example is model-free, deterministic, packaged, and verified after
  fresh import and replay.
- Public security, governance, reproducibility, evaluation, package, and user
  documentation agree on version 0.3.0 and the implemented capability limits.
