  evaluation cells, traces, and reward assessments are evidence. None can
  transition a claim, approve a reviewer, mutate governance policy, promote a
  harness, or advance progress without the existing independent governed
  proposal.
- Handlers receive only family-specific capabilities. Cognitive domain
  objects, collaborators, compilers, evaluators, traces, rewards, and the
  public orchestration facade receive no `RepositorySet`, unit of work,
  governance-write capability, protected answers, or artifact-write authority.
- Reviewer independence is identity-based. Same-model prompt diversity and
  peer majority remain operational observations and cannot satisfy reviewer
  independence.
- Trace admission owns one fresh exact snapshot. Retained traces exclude
  hidden chain-of-thought, provider-native reasoning, secrets, protected
  answers, arbitrary commands, and reversible protected-store locations.
- Reward validity is recomputed from current trace, verifier, artifact,
  environment, coverage, and hacking findings. A high reward cannot erase an
  invalidating finding or authorize promotion.
- All 18 new governed tables are append-only and `WITHOUT ROWID`. Integrity
  reconstruction binds accepted proposal, transaction, audit, policy,
  provenance, and current source state before export or replay.
- Cognitive inspection opens SQLite read-only with `query_only`, verifies the
  workspace before lookup, and exposes no provider, execution, import, tool,
  model, or command option.
- The runtime adds no network, model SDK, shell, arbitrary subprocess, dynamic
  import, `eval`, `exec`, GPU, Kubernetes, reinforcement-learning, or training
  dependency. Packaging tests use subprocesses only in the registered quality
  boundary to build and inspect an isolated wheel.
